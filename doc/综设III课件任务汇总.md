### 一、 核心主线任务（基础框架与分布式）

这部分是本学期必须完成的基础架构和核心功能开发：

1. **底层算子 CUDA C/C++ 实现与对比**
   - **实现**：使用 CUDA C/C++ 实现卷积和池化算子。
   - **性能对比**：对比 NumPy、CuPy 和 CUDA C 三种实现的执行时间。
   - **评估指标**：需包含平均执行时间、加速比、最大绝对误差、相对误差、不同输入规模下的性能变化。
   - **结论分析**：论证 CUDA C 优化是否带来实质收益，并总结各自适用的场景。
2. **单机多进程 PS 架构分布式训练模拟**
   - **架构实现**：模拟 Parameter Server (PS) 结构的分布式训练系统，以理解基本流程和性能瓶颈。
   - **组件职责划分**：
     - **PS**：保存全局参数，接收梯度，聚合并更新参数。
     - **Worker**：读取数据，执行前/反向传播计算梯度并上传。
     - **Launcher**：负责启动 PS 和多个 Worker 进程。
     - **Monitor**：监控训练状态、通信时间、梯度上传/参数拉取时间及整体耗时。
3. **GPU 资源监控与性能瓶颈分析**
   - **开发监控模块**：采集硬件状态（GPU利用率、显存占用/峰值、温度、功耗、CPU利用率）。
   - **采集训练指标**：单 step 训练时间、forward/backward/optimizer update 时间、数据加载时间、样本吞吐量 (samples/sec)。
   - **目标**：分析性能瓶颈，并将采集的数据作为后续 AutoPilot Agent 的分析输入。
4. **自动驾驶任务持续优化**
   - 在训练系统优化后，持续对比自研框架与其他主流框架在同等条件下的训练时间、资源占用等指标。

### 三、 MyFlows AutoPilot Agent 智能调优系统

这是本项目的核心亮点之一，需要设计并实现一个围绕训练过程的智能系统：

1. **核心架构设计**：
   - **Planner**（任务规划器）、**Scheduler**（任务调度器）、**Executor**（任务执行器）。
   - **Memory**（记忆系统）、**Critic/Verifier**（结果校验器）、**Reporter**（报告生成器）。
2. **专业子 Agent 开发**：
   - GPU Monitor Agent、Operator Optimization Agent、PS Training Agent、Transfer Learning Agent、Benchmark Agent。
3. **Agent 高级优化方向（挑战点）**：
   - 利用 **TPE 贝叶斯优化**，同时搜索多个超参（学习率、batch size、冻结层数、worker数），基于历史结果构建概率模型预测最优组合。
   - 实现实时的训练异常检测与自动回滚机制。
   - （高难度）利用蒙特卡洛树搜索 (MCTS) 搜索最优训练策略序列。
