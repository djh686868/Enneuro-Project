# 自动混合精度算法分析

> 本文档为 EnNeuro 框架自动混合精度（Automatic Mixed Precision, AMP）功能的算法层面阐述。

---

## 一、概述

在深度神经网络训练中，降低数值精度可以有效减少显存占用和计算时间，但部分算子对精度敏感，直接全局降精度会导致训练不稳定或精度损失。本框架的自动混合精度功能通过**静态图分析与精度转换节点注入**的方案，在算子级别自动决定精度策略：对数值鲁棒的算子使用低精度（float16）加速计算，对精度敏感算子保持高精度（float32）以确保训练稳定性，在两类算子之间自动插入精度转换节点完成数据流转。同时，框架提供了**动态损失缩放（GradScaler）** 机制，通过放大损失值避免低精度梯度下溢，进一步保证训练的数值可靠性。

---

## 二、算子精度分类

本框架将所有算子按对数值精度的敏感程度划分为三类，分类信息集中维护在 `CastRegistry` 中：

**（1）可降精度算子（`cancast`）**

这类算子的数值计算对精度不敏感，在 float16 下仍能保持足够的计算准确性，适合在低精度下执行以获得加速收益。当前注册的可降精度算子包括：

| 类别 | 算子 |
|------|------|
| 卷积类 | `Conv2d`、`GroupedConv2d`、`Deconv2d` |
| 线性类 | `Linear`、`MatMul` |
| 激活类 | `ReLU`、`Sigmoid`、`Tanh` |
| 池化类 | `Pooling`、`AveragePooling`、`GlobalAveragePooling` |
| 融合类 | `FusedConvReLU` |

**（2）拒降精度算子（`resist_cast`）**

这类算子涉及指数、对数、归一化等数值敏感运算，float16 的有限表示范围和精度可能导致严重的数值误差（如 softmax 的指数溢出、batch normalization 的统计量累积偏差），必须保持 float32 精度。当前注册的拒降精度算子包括：

| 类别 | 算子 |
|------|------|
| 数学运算 | `Sin`、`Cos`、`Exp`、`Log` |
| 归一化 | `BatchNorm2d`、`Softmax` |
| 聚合运算 | `Mean` |
| 融合类 | `FusedConvBNReLU`（内含 BatchNorm，需保持高精度） |

**（3）无精度偏好算子**

未在 `CastRegistry` 中显式注册的算子属于此类。它们不主动要求特定精度，而是根据输入张量的实际精度自适应执行，输出精度由输入精度自然决定。

上述分类策略可总结为以下规则：

$$ \text{算子精度} = \begin{cases} \text{float16（降精度）} & \text{算子} \in \text{cancast} \\ \text{float32（保持高精度）} & \text{算子} \in \text{resist\_cast} \\ \text{由输入精度决定} & \text{其他} \end{cases} $$

值得注意的是，融合算子 `FusedConvBNReLU` 虽然包含了可降精度的 Conv2d 和 ReLU，但由于其内部集成了对精度敏感的 BatchNorm2d，被整体归入拒降精度类别。这一决策体现了"木桶原理"——融合算子的精度约束取决于其内部最敏感的组件。

## 三、精度转换节点

框架定义了三种精度转换算子，用于在图中插入显式的精度转换：

- **`DownCast(dtype)`**：将高精度张量降低至目标低精度（通常 float32 → float16），用于在可降精度算子前将输入转换为低精度。仅当输入精度高于目标精度时才执行转换，否则直接透传。
- **`UpCast(dtype)`**：将低精度张量提升至目标高精度（通常 float16 → float32），用于在拒降精度算子前将输入恢复为高精度。仅当输入精度低于目标精度时才执行转换，否则直接透传。
- **`Cast(dtype)`**：绝对精度转换，无论输入精度如何，强制转换为目标精度。用于用户显式指定的精度控制场景。

三种转换算子的前向传播仅执行数据类型转换（`x.astype(dtype)`），反向传播直接透传梯度（`return gys`），不引入额外的梯度变换。

## 四、自动精度转换算法

该算法在静态图构建与算子融合完成之后执行，遍历图中的函数节点，根据其精度类别决定是否插入精度转换节点。算法流程分为两个核心环节：**输入端精度适配**和**输出端精度传播**。

### 4.1 输入端精度适配

对于每个函数节点，根据其精度类别对输入张量执行不同的前置处理：

- **可降精度算子**：若输入张量的精度高于目标低精度（float16），则在输入张量与算子之间插入 `DownCast` 节点，将输入降至 float16。
- **拒降精度算子**：若输入张量的精度低于目标高精度（float32），则在输入张量与算子之间插入 `UpCast` 节点，将输入提升至 float32。
- **无偏好算子**：不插入任何转换节点，输入精度保持不变。

### 4.2 输出端精度传播

每个函数节点执行完毕后，将其输出张量节点的 `dtype` 属性标记为对应的精度，供下游算子的输入端适配逻辑使用：

- **可降精度算子**：后继张量节点的 `dtype` 标记为 float16；
- **拒降精度算子**：后继张量节点的 `dtype` 标记为 float32；
- **无偏好算子**：后继张量节点的 `dtype` 根据输入张量的实际类型决定。

### 4.3 算法伪代码

```
算法：自动混合精度图转换

输入: 静态计算图 G，目标低精度 dtype（默认 'float16'），目标高精度 UPPER_DTYPE（默认 'float32'）
输出: 插入精度转换节点后的图 G

1.  获取 G 的拓扑排序序列
2.  for each 节点 node in 拓扑序列:
3.      if node 不是函数节点: continue
4.      
5.      ▷ 情况一：节点本身是精度转换算子（Cast / UpCast / DownCast）
6.      if node 对应算子是 Cast 或其子类:
7.          后继节点列表 ← G.获取后继(node)
8.          for each 后继节点 suc in 后继节点列表:
9.              更新 suc.dtype（按 Cast/UpCast/DownCast 语义）
10.         continue
11.     
12.     ▷ 情况二：可降精度算子
13.     if node 对应算子 ∈ CastRegistry.cancast:
14.         前驱节点列表 ← G.获取前驱(node)
15.         for each 前驱节点 pre in 前驱节点列表:
16.             if pre.dtype 精度高于 dtype:
17.                 ▷ 插入 DownCast: pre → DownCast → 新Tensor → node
18.                 G.移除边(pre → node)
19.                 创建 DownCast(dtype) 函数节点
20.                 执行 DownCast 前向得到输出张量，创建对应张量节点
21.                 G.添加边(pre → DownCast节点)
22.                 G.添加边(DownCast节点 → 新张量节点)
23.                 G.添加边(新张量节点 → node)
24.             else:
25.                 G.重建边(pre → node)    ▷ 保持原连接，确保输入顺序正确
26.         后继节点列表 ← G.获取后继(node)
27.         for each 后继节点 suc in 后继节点列表:
28.             标记 suc.dtype ← dtype      ▷ 传播低精度标记
29.         continue
30.     
31.     ▷ 情况三：拒降精度算子
32.     if node 对应算子 ∈ CastRegistry.resist_cast:
33.         前驱节点列表 ← G.获取前驱(node)
34.         for each 前驱节点 pre in 前驱节点列表:
35.             if UPPER_DTYPE 精度高于 pre.dtype:
36.                 ▷ 插入 UpCast: pre → UpCast → 新Tensor → node
37.                 G.移除边(pre → node)
38.                 创建 UpCast(UPPER_DTYPE) 函数节点
39.                 执行 UpCast 前向得到输出张量，创建对应张量节点
40.                 G.添加边(pre → UpCast节点)
41.                 G.添加边(UpCast节点 → 新张量节点)
42.                 G.添加边(新张量节点 → node)
43.             else:
44.                 G.重建边(pre → node)    ▷ 保持原连接
45.         后继节点列表 ← G.获取后继(node)
46.         for each 后继节点 suc in 后继节点列表:
47.             标记 suc.dtype ← UPPER_DTYPE  ▷ 传播高精度标记
48.         continue
49.     
50.     ▷ 情况四：无精度偏好算子
51.     前驱节点列表 ← G.获取前驱(node)
52.     后继节点列表 ← G.获取后继(node)
53.     suc_dtype ← 前驱节点的精度（取最高者）
54.     for each 后继节点 suc in 后继节点列表:
55.         标记 suc.dtype ← suc_dtype      ▷ 精度自然传递
56. 
57. end for
58. return G
```

### 4.4 转换示例

以下展示一个典型混合精度转换前后的计算图变化：

```
转换前（精度尚未标记）:              转换后（混合精度）:

  Tensor (float32)                      Tensor (float32)
       │                                      │
    Conv2d                              DownCast (→float16)
       │                                      │
  Tensor (float32)                      Tensor (float16)
       │                                      │
  BatchNorm2d                             Conv2d (float16)
       │                                      │
  Tensor (float32)                      Tensor (float16)
       │                                      │
     ReLU                               UpCast (→float32)
       │                                      │
  Tensor (float32)                      Tensor (float32)
                                         │
                                    BatchNorm2d (float32)
                                         │
                                    Tensor (float32)
                                         │
                                   DownCast (→float16)
                                         │
                                    Tensor (float16)
                                         │
                                       ReLU (float16)
                                         │
                                    Tensor (float16)
```

Conv2d 和 ReLU 属于可降精度算子，在 float16 下执行；BatchNorm2d 属于拒降精度算子，保持 float32 执行。两类算子之间通过 `DownCast` 和 `UpCast` 节点桥接精度差异。

## 五、动态损失缩放

### 5.1 问题背景

float16 的最小正规表示约为 $6.1 \times 10^{-5}$。在训练过程中，部分参数的梯度值可能极小，直接以 float16 表示会导致**梯度下溢**（gradient underflow），即小梯度被截断为零，阻碍参数更新。动态损失缩放通过在反向传播前将损失值放大一个缩放因子，使梯度值整体上移入 float16 的可表示范围，在参数更新前再将梯度还原。

### 5.2 缩放算法

```
算法：动态损失缩放（GradScaler）

超参数:
    init_scale = 32768.0        ▷ 初始缩放因子
    growth_factor = 2.0         ▷ 增长倍数
    backoff_factor = 0.5        ▷ 回退倍数
    growth_interval = 2000      ▷ 连续无溢出步数阈值
    min_scale = 1.0             ▷ 最小缩放因子

状态变量:
    scale_factor ← init_scale   ▷ 当前缩放因子
    step_count ← 0              ▷ 连续无溢出步数计数

1.  过程 scale(loss):
2.      return scale_factor * loss          ▷ 放大损失，使梯度上移

3.  过程 step(optimizer):
4.      has_overflow ← False
5.      for each param in optimizer.params:
6.          if param.grad 为 None: continue
7.          if param.grad 中存在 inf 或 nan:
8.              has_overflow ← True
9.              break
10.     
11.     if has_overflow:                     ▷ 梯度溢出：放弃本次更新
12.         optimizer.zero_grad()            ▷ 清除无效梯度
13.         scale_factor ← scale_factor × backoff_factor
14.         scale_factor ← max(scale_factor, min_scale)
15.         step_count ← 0
16.     else:                                ▷ 无溢出：正常更新
17.         for each param in optimizer.params:
18.             if param.grad 为 None: continue
19.             param.grad.data ← param.grad.data / scale_factor  ▷ 还原梯度
20.         optimizer.step()                 ▷ 执行参数更新
21.         step_count ← step_count + 1
22.         if step_count ≥ growth_interval:
23.             scale_factor ← scale_factor × growth_factor
24.             step_count ← 0
```

### 5.3 缩放策略分析

缩放因子 $S$ 采用**自适应增长-回退**策略动态调整：

- **增长阶段**：当连续 $N_{\text{interval}} = 2000$ 步未检测到梯度溢出时，认为当前缩放因子较为保守，将其翻倍（$S \leftarrow S \times 2$），以尝试更大的缩放幅度来覆盖更小的梯度。
- **回退阶段**：一旦检测到任何参数梯度中出现 `inf` 或 `nan`（由过大缩放导致的上溢），立即放弃本次参数更新（梯度已不可靠），将缩放因子减半（$S \leftarrow S \times 0.5$），并重置无溢出计数器。
- **下限保护**：缩放因子不低于 `min_scale = 1.0`，确保 loss 不会被缩小（即缩放机制不会反向抑制原本正常的梯度）。

初始缩放因子 $S_0 = 32768$ 是根据经验选取的保守值，足以覆盖大多数网络结构中的小梯度，通常在前几个 step 即可通过增长机制收敛到合适的动态范围。

## 六、训练循环中的完整使用流程

```
算法：混合精度训练循环

输入: 模型 M，优化器 optimizer，数据加载器 dataloader，损失函数 loss_fn
输出: 训练后的模型参数

1.  scaler ← GradScaler()
2.  for each (input, target) in dataloader:
3.      ▷ 阶段一：混合精度前向传播（自动插入 DownCast/UpCast）
4.      with autocast(dtype='float16'):
5.          output ← M(input)
6.          loss ← loss_fn(output, target)
7.      
8.      ▷ 阶段二：缩放损失并反向传播
9.      scaled_loss ← scaler.scale(loss)     ▷ loss × scale_factor
10.     scaled_loss.backward()               ▷ 低精度梯度计算
11.     
12.     ▷ 阶段三：梯度检查与参数更新
13.     scaler.step(optimizer)               ▷ 还原梯度 → 溢出检查 → 更新
14. end for
```

## 七、设计要点总结

1. **白名单分类机制**：通过 `CastRegistry` 的 `cancast` 和 `resist_cast` 两个白名单实现精度策略的集中管理，新增算子只需在对应列表注册即可获得精度策略，具有良好的可扩展性。

2. **事先生成式图改写**：精度转换节点（`DownCast`/`UpCast`）在训练开始前一次性插入静态图，而非在每次前向传播时动态判断。这种方式避免了运行时的重复精度检查开销，转换后的图可被图执行器高效复用。

3. **前反向精度解耦**：精度转换算子（`Cast`/`DownCast`/`UpCast`）的反向传播直接透传梯度，不做精度转换。这意味着反向传播的梯度精度由上游算子自然决定，避免了精度转换算子对梯度链路的干扰。

4. **自适应缩放因子**：`GradScaler` 采用增长-回退的自适应策略，在训练过程中自动寻找合适的缩放幅度，无需人工调参。缩放因子仅在梯度溢出时瞬时降低，在长时间稳定训练中逐步恢复，兼顾数值稳定性与训练效率。

5. **融合算子精度一致性**：`FusedConvBNReLU` 因内含 BatchNorm 而被归入拒降精度类别，整个融合算子以 float32 执行。这保证了融合优化与混合精度优化的兼容性——融合消除的是算子边界和中间显存，精度策略消除的是不必要的精度冗余，两者在静态图上叠加生效且互不冲突。
