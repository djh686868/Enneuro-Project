# 综设III 任务拆分明细表（执行台账）

> 版本：v1.0 ｜ 日期：2026-09-02 ｜ 配套方案：`doc/综设III_任务拆解与分工方案.md`
> 用途：任务分派与进度跟踪。每周组会更新「状态」列，里程碑节点做全表盘点。

## 使用说明

- **难度**：★☆☆ 易（0.5–2 人日）｜ ★★☆ 中（2–5 人日）｜ ★★★ 难（1–2 周，需调研/反复调试）
- **负责人**：A–F 为代号（见方案第六节），斜杠后为协作人
- **状态**：`未开始` → `进行中` → `待验收` → `完成`（或 `裁剪`）
- **验收标准**：与测试计划分层对应（L0 单元 / L1 数值一致性 / L2 集成 / L3 端到端 / L4 性能）

## 依赖关系总览（关键路径）

```
M7-01 测试基建 ──┬──> 所有模块的单测/回归
M7-03 CR-1/CR-2 ────> M2 分布式（M2-02/04）
M2-01 协议 ──> M2-02 PS ──> M2-03 Worker / M2-04 Launcher ──> M2-06 同步 ──> M2-08 等价性 ──> M4-09 子Agent
M1-01 环境 ──> M1-02 naive ──> M1-03 im2col ──> M1-04 tiled ──> M1-06 反向 ──> M1-09 benchmark

M4-02..05 核心 ──> M4-12 TPE ──> M8-03 优化复测
```
